- Sobre dark: blanco o accent-bright
- Sobre claro: text (#2A2A3E) o secondary (#555366)

## 5. Estilo visual

### Principios
Identidad **dark, industrial, minimalista** — fiel al sitio web.

1. **Dark theme dominante:** Fondos #1F2036 con texto claro como base de todo
2. **Texturas sutiles:** Patrones geométricos a baja opacidad (3–8%) sobre fondos dark
3. **Gradientes discretos:** De primary a secondary (135°), nunca llamativos
4. **Bordes finos:** 1px en rgba(255,255,255,0.06–0.12) para separar secciones
5. **Geometría industrial:** Esquinas redondeadas suaves (8–16px), sin orgánico
6. **Espacio generoso:** Mucho padding, contenido respira

### Texturas (CSS)
```css
/* Grid sutil */
background-image: 
  linear-gradient(rgba(255,255,255,0.03) 1px, transparent 1px),
  linear-gradient(90deg, rgba(255,255,255,0.03) 1px, transparent 1px);
background-size: 40px 40px;

/* Dots sutiles */
background-image: radial-gradient(rgba(255,255,255,0.05) 1px, transparent 1px);
background-size: 20px 20px;

/* Líneas diagonales */
background-image: repeating-linear-gradient(
  45deg, transparent, transparent 20px, 
  rgba(255,255,255,0.03) 20px, rgba(255,255,255,0.03) 21px
);
```
En Canva: usar elementos de patrón en blanco con opacidad 3–8% sobre fondos primary.

### Iconografía
- Estilo lineal (stroke, no fill) en accent (#7B8FBF) o accent-bright (#9AADDA)
- Trazo: 1.5–2px, geométrico, sin decoraciones
- Tamaño mínimo: 24×24px

### Fotografía
- Fotos industriales: almacenes, aduanas, etiquetas, productos, impresoras
- Tonalidad fría, desaturada
- Overlay: rgba(22, 23, 41, 0.7) para legibilidad sobre fotos
- Evitar stock genérico de "gente en oficina"
